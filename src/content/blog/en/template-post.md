This is **placeholder copy**. It exists so the blog template, typography and layout can be reviewed before the real first post is written. Delete this file (and its Korean twin) when that post lands.

## Headings, paragraphs, links

Body text is set for long reading: a comfortable measure, generous leading and a link style that [looks like a link](/en/blog/). Inline `code` gets a small mono treatment.

> A pull quote gets a safety-orange rule and display type. Use it sparingly.

### Lists

- Posts are plain Markdown files, one per language.
- The same filename in `en/` and `ko/` links the two translations.
- Front matter controls title, date, tags and an optional cover image.

1. Write the post.
2. Translate it.
3. Get it proofread, then approved.

## Media

Screenshots drop in as ordinary Markdown images and pick up the hard-edged frame automatically:

```md
![Alt text describing the screenshot](/media/posts/my-screenshot.png)
```

Video and trailers can be embedded with a plain `<video>` or `<iframe>` tag, which also gets the frame and a 16:9 ratio.
