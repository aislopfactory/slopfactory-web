# Korean glossary (EN → KO)

Owner: Translator. Source: the live site https://slopfactory.a-bba.dev/ (Home, About, Our Games, Orbit Hop and Line Inspector pages, both devlogs) and the shipped UI strings in `orbit-hop/play/game.js` and `line-inspector/play/game.js`. Read the [style guide](ko-style-guide.md) first for tone, particles and length rules.

**How to use this table**

- **Keep EN**: write the name in Latin letters, in Korean text too. The Korean reading in brackets is only there so you pick the right particle (see "Particles after English names" below). It is not shown to players.
- **Translate**: use the Korean word.
- **Transliterate**: write it in Hangul as shown.
- If a term is missing, add it here before using it anywhere, so the next game and post use the same word.

## 6. Particles after English names

Korean particles depend on the last sound of the word as read aloud. For names kept in English, pick by the Korean reading in the tables above:

| Name | Ends in | 은/는 | 이/가 | 을/를 | 과/와 |
|---|---|---|---|---|---|
| Orbit Hop (홉) | consonant | Orbit Hop은 | Orbit Hop이 | Orbit Hop을 | Orbit Hop과 |
| Line Inspector (터) | vowel | Line Inspector는 | Line Inspector가 | Line Inspector를 | Line Inspector와 |
| Slop Factory (리) | vowel | Slop Factory는 | Slop Factory가 | Slop Factory를 | Slop Factory와 |
| Game Factory (리) | vowel | Game Factory는 | Game Factory가 | Game Factory를 | Game Factory와 |

Never put a particle straight after a code placeholder (`${name}`), because the value changes. See style guide §6.
